# v0.2.6

## 修复

- **打开应用白屏**：应用只在启动时加载一次界面，若 DSH 服务尚未就绪就会停在静态的"还没起来"页面且不再重试。现在失败会自动退避重试，并持续探测服务端口，服务一就绪立即进入界面；重新打开应用也会刷新页面。
- **手机整体断网**：内置 DNS 转发器若停止，系统的 DNS 请求会指向无人监听的端口，表现为 DSH 发送失败、浏览器打不开网页。现在有看门狗在 30 秒内自动恢复，并每 5 分钟做一次真实解析探测；连续恢复失败时会自动撤掉重定向，避免把网络卡死。
- **DSH 服务被系统回收**：服务停止后会由看门狗自动拉起，不再需要手动打开应用唤醒。
- Root 版部署时自动安装并启动看门狗。

## 升级

- versionCode 10 / v0.2.6。
- **本版更换了签名**：需要先卸载旧版再安装。Termux 环境与 `~/.dsh-api-key` 不受影响，App 内保存的 API Key 需重新填写一次。
- 从下一版起签名固定，可直接覆盖安装。

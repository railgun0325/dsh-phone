# v0.2.11

## 修复

- **手机里「新建文件夹」报 `EACCES: permission denied`**：与 root 和系统权限无关。Termux 家目录的属主/权限在拷贝部署文件的过程中被改成了其他用户（模式 775），应用以自己的用户身份在该目录里只有读权限，因此无法新建文件或文件夹。
  现在部署流程会自检并修正家目录的属主与权限，App 在拷贝部署文件后也会恢复它。

## 升级

- 覆盖安装即可（versionCode 15 / v0.2.11）。
- 已经出现该问题的设备：安装后点一次「一键部署」会自动修复，也可在 Termux 执行
  `chown $(id -u):$(id -g) ~ && chmod 700 ~`。
